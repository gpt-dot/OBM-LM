§ 0

设计方法论：发散 × 收敛

Methodology

单用头脑风暴，产出的是"一堆有趣但无法落地的点子"；单用 TRIZ，容易在既有方案上打转、缺乏真正的新颖度。 本设计将两者组成一条流水线：

创新产出 = 头脑风暴的发散度 × TRIZ 的收敛质量（乘法关系，任一为零则创新为零）。
头脑风暴负责"把解空间撑大"（数量优先、延迟评判、欢迎疯狂）；TRIZ 负责"在矛盾最尖锐处下刀"（用矛盾定义问题、用原理生成解）。

2.1 理想最终结果 IFR 理想化法则

IFR 陈述：「智能功能在需要的那一刻涌现，只消耗本来闲置的资源，边际成本趋近于零， 而系统自身趋于"消失"——没有需要维护的静态模型，只有持续代谢的过程。」

这句"疯话"直接派生出三条硬约束：① 能力必须按需生长（而非预训练完备）；② 必须吃"闲置资源"（夜间算力、内部遗忘容量、分歧信号）； ③ 结构必须可自我维护（剪掉"维护者"本身）——这正是后面所有机制的源头。

2.5 裁剪（Trimming）——把最贵的部件删掉

TRIZ 裁剪法则问："如果删掉这个部件，谁来完成它的功能？"本设计裁掉了现代深度学习最昂贵的四个部件：

① 全局反向传播（最贵：全参数梯度同步）→ 由"局部赫布学习 + 合同市场定价"替代；
② 静态参数文件（训练完就冻结）→ 由"持续代谢"替代，部署后仍在做梦；
③ 统一全局损失函数 → 由"每个细胞各自的合同目标"替代；
④ 固定架构 → 由"按需分裂/合并"替代。

裁剪后的系统更简单、更便宜、更可扩——这正是"理想化"的方向：功能保留，结构消失。

2.6 进化法则定位（S 曲线判断）

按 TRIZ 技术系统进化法则判断：Transformer"大力出奇迹"范式已进入 S 曲线成熟期——数据接近枯竭、能耗线性上涨、 Scaling 收益递减。 进化法则给出的出路：15 动态化（静态网络→动态结构）、子系统不均衡进化（训练系统极发达，代谢/记忆/路由系统极原始——机会就在这里）、 迁移到超系统（单体模型 → 模型生态系统）。OBM 正是这三个方向的合并。

§ 3

Phase 3 · 算法综合：衔尾蛇 OBM

The Algorithm
命名：衔尾蛇（Ouroboros）——咬住自己的尾巴。系统吃掉自己的旧结构（代谢/蒸馏），长出新的自己（分裂/新细胞）； 同时"清醒—做梦"循环不息。梦网（Mesh）指概念细胞之间由合同织成的动态网络。

3.1 设计哲学：三条反直觉定律

定律一 · 越大越小
Bigger by being smaller

整体智能随规模增长，但每个细胞恒定微小（4–8 层微型网络）。规模来自"数量 × 连接"，不是单体体积。对应 PC1 的空间分离。

定律二 · 越学越小
Learning shrinks the model

每次学习周期结束后，总参数量只减不增：梦境期把知识压缩成更少、更专用的连接，凋亡细胞回收参数。智能是压缩率，不是体量。

定律三 · 越难越深
Deeper for harder tasks

简单任务走反射弧（单跳，毫秒级）；困难任务递归展开更深层级——细胞调用细胞的细胞。对应 TC3 的条件分离：System 1 / System 2。

3.3 五大核心机制

M1分形细胞 · Fractal CellTRIZ 原理 1 分割 · 17 维数变化 · 33 均质性
解决 PC1「大 vs 小」

所有细胞共享同一套微型架构模板（注意力 + 状态空间的双通道），该模板在系统内所有层级重复出现——这正是 TRIZ 33 均质性的极端应用：同构对象相互作用时最稳定。 关键设计：细胞的"深度"不是固定的，而是惰性展开的——只有当路由判定"问题够难"时，细胞才递归调用下一层子细胞（内存中只物化当前需要的层级）。 因此系统拥有有界内存、无界有效深度。

M2分歧驱动路由 · Divergence-Driven RoutingTRIZ 原理 23 反馈 · 24 中介
把"内部矛盾"变成学习燃料（呼应 TC3 与资源分析）

传统门控（MoE）按相似度路由——喂给最"懂"的专家，这会让专家越来越狭隘。OBM 反过来：按分歧度路由， 把输入同时送给一群"看法互相冲突"的细胞。分歧越大 = 系统对自己的预测越不确定 = 信息量越大（KL 散度直接量化它）。 冲突的裁决结果写入"判例库"，成为新的合同条款。系统主动寻找自己最不懂的时刻——那是唯一值得学习的时刻。

M3合同市场 · Contract MarketTRIZ 原理 28 场替代 · 15 动态化
解决 PC3「连接多 vs 少」+ 裁剪掉全局反传

细胞间的连接不是静态权重，而是双边合同：每条合同记录可靠性历史、服务成本与最近一次"违约"（预测失手）。 路由决策 = 在预算约束下做一次迷你采购：选分歧度最高、报价最低的组合。合同按市场价生灭——连接因此有了价格、保险与淘汰机制， 知识传播靠"经济"而不是"梯度回传"，天然可并行、可容错、可解释（推理路径 = 一串被执行的合同）。

M4梦境代谢 · Dream MetabolismTRIZ 原理 20 连续性 · 25 自服务 · 26 复制
解决 PC2「快 vs 慢」、PC4「稳定 vs 可塑」+ 实现"越学越小"

系统周期性进入离线梦境态（理想时机：算力低谷），执行四件事：反刍（按"意外度"采样重放当日经历，先过信息瓶颈再存储）； 反事实（对关键决策点跑"如果当时选另一条路"的模拟，等价于自己给自己出考卷 #07）； 蒸馏（把梦境中反复出现的激活模式固化为一个新细胞或一条新合同）；凋亡（剪除效用低于阈值的细胞，参数进回收池； 对某类输入误差方差过大的细胞执行分裂复制——#15）。总参数量由此保持恒定上界，模型越训练越紧凑。

M5双向时间推理 · Bidirectional InferenceTRIZ 原理 2 抽取 · 24 中介
解决可解释性与因果归因

每个概念细胞同时训练两个方向：正向从证据预测结论（演绎），反向从结论反推最可能的证据（溯因）。 输出任何结果时，系统必须同时给出"支持我的证据链"——解释不是事后贴上去的，而是推理本身的副产品。反向通道还让系统能做因果对比： "如果撤掉证据 E，结论会不会变？"

3.6 学习规则：没有全局反向传播的三重学习

  • 在线 · 局部赫班学习：每个被激活的细胞只根据自己前后的激活关联更新（赫布规则），无梯度跨层回传；

        y_t = ReflexArc(p_t)                    # 毫秒级直达
    else:
        y_t = DeepThink(A*, p_t, depth = ⌈log₂|C|⌉·τ)  # 合同调用链，附溯因解释

    # ④ 在线学习：无全局反传
    for c ∈ A*:
        ΔW_c = η·Hebbian(p_t, c) + PricingTerm(E)   # 局部更新 + 合同记账
    updateContracts(E, 表现记录)
    把 (x_t, 意外度) 压入 R                      # 只留高意外度片段

    # ⑤ 周期性做梦（离线，吃闲置算力）
    if t mod T_dream == 0:  DreamPhase(S, C, E, R)

DreamPhase(S, C, E, R):
    for r ∈ sample(R, 按意外度):                # 反刍：压缩后重放
        前向重放 r; 反向重放 r                    # M5 双向时间
        for 决策点 d ∈ r:                      # 反事实：自生成反例
            模拟 "若当时选择 ¬d" 的后果，记录 Δ效用
    蒸馏: 梦境中高频激活模式 → 新细胞 c_new ∈ C
    凋亡: for c ∈ C: if u_c < θ_die: 溶解 c, 参数 → 回收池
    分裂: for c ∈ C: if Var_k(Err_{c,k}) > δ: c → (c_a, c_b) 复制+变异
    合并: 相邻且高相似的细胞 → 合并，参数取合同加权平均

创新点总结

Summary
  1. 方法论层面：完整演示"头脑风暴（22 想法，8 入选）× TRIZ（IFR + 3 技术矛盾 + 4 物理矛盾 + 13 条发明原理 + 资源分析 + 裁剪）"的可用创新流水线，可复用到任何 AI 系统设计。
  2. 范式层面：把 AI 从"训练出来的静态模型"重构为"持续代谢的生态系统"——三条定律（越大越小 / 越学越小 / 越难越深）均直接源自矛盾分离，而非修辞。
  3. 算法层面：五大机制（分形细胞、分歧驱动路由、合同市场、梦境代谢、双向时间推理）互相咬合：分歧路由产生学习信号，合同市场完成信用分配，梦境代谢完成巩固与自我裁剪——构成闭环。
  4. 工程层面：零全局反向传播、恒定存储上界、算力峰值转移到低谷期——直击大模型的能耗墙与持续学习两大痛点。
